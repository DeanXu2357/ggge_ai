## 顯示方格格網（vision）

- **直線 pitch≈128 穩定**；**橫線間距 108→123 隨 y 遞增＝縱向透視**（下方格
  較寬）→ lattice 以原始線位表示（cols, rows），不概括成單一 cell size。
  bridge 的 `cell_size=95` 是舊近似，格座標權威化（定義檔 cells 由格線量測）
  為 #25 後續迭代。
- `read_grid_lattice` 三重閘：頭尾 gap 出帶裁剪（排除 UI 邊假線）、線數門檻
  （col≥6/row≥4）、gap 全帶內＋均勻度 ≤35（排除無格線幀的精靈假線與
  單位移動模式移動藍格的半格邊緣）。region 底緣 y780（排除提示帶頂邊假線；
  HUB_SCAN 弧偵測本就止於 y790）。
- `_observe_map` 對每幀自動偵測：有 lattice 就把弧座標吸附到格心（screen
  空間），無格線幀原樣通過——`_scout_local`（無格線）零影響。
- serpentine 前 `set_battle_grid(True)`、掃畢 finally 關回；toggle 未驗證
  成功＝fail-soft 照舊無格線掃（流水帳 `battle_grid` 事件記錄）。
