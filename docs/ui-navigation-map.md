## 外層快速導航規則（使用者 0730 定則）

外層畫面若下緣出現**底部導航列**（主畫面／強化／開發／關卡／
個人基地／機體補給／選單），可**直接點擊目標按鈕跳轉**，不必
先回主畫面再逐層走。程式含義：

- 底部導航列＝外層畫面的強分類錨點：見列＝人在外層、可全域跳轉。
- 批 3 外層 UI 操作的導航原語以此為主：跳轉一步到位，回退鏈只在
  無導航列的畫面（彈窗、詳情頁、關卡內）才需要。
- 已標定座標：強化 (610,1021)、關卡 (1220,1021)。其餘同列
  （y≈1021）估算待校準：主畫面 ~370、開發 ~915、個人基地
  ~1530、機體補給 ~1815、選單 ~2120——後續 agent 使用時順手
  實測回填；注意當前所在分頁的按鈕可能高亮或隱藏，校準時記錄。

## 關卡完成狀態標示（外層判定權威）

關卡節點構造（上→下）：關卡編號＋難度箭頭 → 三星旗列 →
3D 平台模型 → 平台正下方狀態徽章。四態：

| 狀態 | 徽章 | 星旗 | 平台環色 |
|---|---|---|---|
| 未通關（下一關） | 無徽章＋平台上方黃色 NEXT 箭頭 | 全灰 | 紅橙 |
| CLEAR | 藍底勾＋「CLEAR」 | <3 金 | 藍青 |
| COMPLETE | 藍底勾＋「COMPLETE」＋第二行「3/3」 | 3/3 金 | 藍青 |
| 鎖定 | 平台白色掛鎖 | 無星旗列 | 暗紅 |

- COMPLETE ⇔ 三星（實機確認）。CLEAR 與 COMPLETE 環色相同，
  **辨識訊號是徽章文字與 3/3 計數，不是環色**；未通關靠紅橙環
  ＋NEXT 箭頭。
- 略過資格（使用者定則）：CLEAR＝不可略過、COMPLETE＝可略過。
  按鈕實測：未通關＝灰字＋掛鎖；COMPLETE＝亮藍框白字；上方均有
  橙色「剩餘 X/3」。**缺口**：CLEAR（2 星）態的略過按鈕樣貌未
  獨立截證，資格以使用者定則為準。

## 新故障模式：前景卡死（0729 實測）

LOGIN BONUS 彈窗上發生 Unity 渲染／輸入停擺：畫面靜止偏暗、
連續 5 種互動（三處 tap、獎勵格 tap、BACK）全無反應；
`dumpsys activity` 顯示遊戲仍是 mResumedActivity、無系統鎖——
**與歷來硬凍不同：adb 與 HOME 鍵全程存活，只有遊戲自身的幀泵
與觸控處理卡住**。復原：KEYCODE_HOME → 桌面點遊戲圖示 (355,234)
回前景，畫面立即變亮恢復正常。

設計含義（批 2）：迴圈需要「tap 無效看門狗」——連續 N 次操作後
畫面無變化 ⇒ HOME 循環復原反射；否則實戰中會無錯誤地無限空轉。

## 日期變更對話框與觸控鎖疊加陷阱（0730 實測）

午夜跨日觸發系統對話框：「更新資料／日期已改變。將返回主畫面。」
＋「前往主畫面」鈕（約 1178,850）。陷阱：**省電觸控鎖可以疊在
對話框之上**——畫面變暗、tap 全被吞、但轉圈動畫存活，極易誤診為
對話框卡死（0730 掃描 agent 連點 4 次無效即此因）；復原＝先解鎖
swipe（1164 430→1164 60）再點按鈕，一次成功。點掉後回主選單。
批 2／3 反射組要收這個彈窗；跨日同時代表每日重置（略過次數、
每日使命）。
