# UI 規格（實機標定權威）

裝置 R5CRC37JBYJ，2340x1080 橫向；座標為實測點擊座標。本檔收錄**耐久的
UI 規則與座標**——標定過程、事故軼事與批次脈絡在 git 與
docs/archive/{ui-navigation-map,battle-settings-ui}.md。程式引用以樹上
實作為準（`runtime/screens.py` 簽名、`runtime/device.py` 危險帶、
`runtime/entry.py` 導航閘）。

## 外層導航

- **底部導航列＝外層強分類錨點**：見列＝人在外層，可直接點目標鈕全域
  跳轉，不必回主畫面逐層走。回退鏈只在無導航列的畫面（彈窗、詳情頁、
  關卡內）需要。
- 已標定：強化 (610,1021)、關卡 (1220,1021)。同列估算待校準：主畫面
  ~370、開發 ~915、個人基地 ~1530、機體補給 ~1815、選單 ~2120（當前
  分頁的鈕可能高亮或隱藏）。
- 主選單：頂部 RANK／EN／鑽石／資金；左側欄 公告／禮物／使命
  (234,668)／商店。
- 啟動收乾：LOGIN BONUS 彈窗 → (1150,1000) → 公告彈窗（**約 1.5 秒
  載入空窗近全黑，分類器要容忍**）→ 關閉 (1170,993) → 主選單。
- 隊伍資源三頁（強化 hub 側欄）：單位（預設）／角色 (357,536)（內含
  招募抽卡入口，**勿點**）／支援人員 (357,685)。

## 關卡 hub

- 主選單 → 關卡 → 磁貼：MAIN STAGE (640,803)／EVENT／MASTER LEAGUE／
  UPGRADE STAGES／ETERNAL ROAD (1930,763)。
- MAIN STAGE 系列輪播：**小步幅 swipe（約 500px）逐卡確認**——大步幅
  一次跳 6-7 張會系統性漏卡。完整系列順序權威＝
  `assets/catalog/story/_series_index.json`。HARD 關直接接在 NORMAL 軌
  BOSS 關後同一條節點軸，同一 swipe 續行。
- 系列卡 → 系列資訊（完成報酬／建議戰力／登錄狀況／選擇 (1927,903)）
  → 關卡列表＋單關右欄（標題、星旗、建議戰力、地形、所需 EN、報酬欄、
  剩餘 X/3、出擊準備）。
- **完成狀態四態**（外層判定權威）：

  | 狀態 | 徽章 | 星旗 | 平台環色 |
  |---|---|---|---|
  | 未通關（下一關） | 無徽章＋黃色 NEXT 箭頭 | 全灰 | 紅橙 |
  | CLEAR | 藍底勾「CLEAR」 | <3 金 | 藍青 |
  | COMPLETE | 藍底勾「COMPLETE」＋「3/3」 | 3/3 金 | 藍青 |
  | 鎖定 | 平台白色掛鎖 | 無星旗列 | 暗紅 |

  CLEAR／COMPLETE 環色相同——**辨識靠徽章文字與 3/3 計數**。略過資格：
  CLEAR 不可、COMPLETE 可（使用者定則；CLEAR 態按鈕樣貌缺獨立截證）。
- 永恆之路：單一縱向捲動、三難度區段堆疊各自從 No.1 起編
  （NORMAL 23＋HARD 32＋EXPERT 27＝82）；鎖定節點右欄仍可讀（僅出擊鈕
  不可用）。**MAIN STAGE 相反：鎖定關不可點選**（右欄不動）——兩系統
  行為不同。
- 使命兩入口：Eternal Road 右上 (2059,70)＝事件使命；主選單側欄
  (234,668)＝每日／累積／事件三分頁。
- 節點特例：HARD 軌星列有第四顆異色星（意義未定）；初鋼第 1 關＝
  GUEST BATTLE 特殊節點（無星列／地形／EN 欄，橙色「出擊」鈕）。

## 進戰鬥硬閘門（每次進場必做）

1. **AUTO=OFF**。開關 (1815,52)（關卡資訊頁與戰鬥內同位），狀態沿用
   上次設定——「不碰」不是安全策略，必須主動讀取確認。三態像素簽名：
   OFF＝暗底 (34,42,53)~(36,43,59) 白字；ON 待機＝青亮 (38,107,138)；
   ON 執行中＝實心紅 (174,55,57)。判定規則：**暗＝OFF 勿點**（點了會開）。
2. **15 秒逾時**：前次 AUTO 開著時，關卡資訊頁 15 秒自動進場——閘門
   必須在 15 秒內完成讀取與關閉（解鎖等前置延遲算進去）。隱藏關觸發
   彈窗同為 15 秒。**應戰窗（反擊／閃避／防禦）沒有逾時**。
3. **輔助格線=ON**：沙盤幾何以格為單位；開關流程在 `battle/settings.py`，
   狀態同樣沿用上次設定。進地圖後複核：單位不自行行動＋格線可見。
4. 條件頁「TAP TO NEXT」陷阱：觸控鎖解鎖的 wake-tap 可能誤觸直接入圖；
   在關卡資訊頁跑 ensure_unlocked 後要重新截圖確認還在原頁。
5. 出擊準備（prep）按鈕帶：**出擊 (1930,970)**；下緣由左至右＝替換部隊
   ／變更配屬／全部編制／**自動編制 (1496,1010)**（會改編成，
   auto_deploy 危險帶絕對擋下；取消鈕 (971,1009)）。**全部編制
   (~1208,1010) 與對話框通用關閉鈕 (~1170,993) 重疊無法設帶**——prep
   畫面勿盲點下緣中段。

## 我方單位選擇態視覺簽名

點擊我方單位後：鏡頭以該單位置中＋行動 UI；移動範圍格內再畫一圈
**雙邊線小格**——全畫面大量雙邊線格是最強的我方選擇態簽名。可行動格
落入敵攻擊範圍顯示**驚嘆號**、落入地圖砲射程顯示**鎖定圖案**。
用途：①ALLY 裁決的獨立視覺證據 ②置中保證（被點格必在螢幕中心，
可當重錨依據）③驚嘆號／鎖定＝免費的敵方威脅範圍情報。

## 陷阱與故障模式

- **省電觸控鎖可疊在任何畫面之上**（含對話框、關卡列表）：畫面變暗、
  tap 全被吞、轉圈動畫存活，易誤診為卡死。復原＝解鎖 swipe
  (1164,430)→(1164,60) 再操作。
- 跨日對話框：「日期已改變。將返回主畫面」＋前往主畫面鈕 (~1178,850)；
  可能與觸控鎖疊加（先解鎖再點）。跨日＝每日重置（略過次數、每日使命）。
- **前景卡死**：遊戲幀泵與觸控停擺但 adb／HOME 存活（dumpsys 仍
  mResumedActivity）。復原＝KEYCODE_HOME → 桌面點遊戲圖示回前景。
  程式含義：連續 N 次 tap 畫面無變化 ⇒ HOME 循環復原反射。
- **棄戰後游標飄移**：回關卡列表後選中節點自動跳下一關——重入**不得
  沿用「當前選中」**，每次進場明示點選目標節點並複核右欄標題
  （`runtime/entry.py` `select_stage`；sweep_scan 一律帶 `--stage-node`）。
- 遊戲登入逾時錯誤 300：唯一鈕返回標題；恢復流程＝標題→下載→登入
  獎勵→公告→主頁。
