# 盤面掃描覆蓋模型 v2 派工規格（2026-07-30 使用者核可）

0730 晚使用者定向＋三輪問答定案（吃指令／重複執行／無標的比對
／邊界與缺口區分皆有裁示）。取代現行「各方向平移次數」制的
覆蓋簿記。
定位：**成功不依賴縮小**——縮小只是減少截圖次數的最佳化；
認知缺口由資料結構顯式暴露，缺口導向補掃、收斂到無缺口為止。
前置依賴：驗證輪修正批（pinch 搬遷等五項）先入庫。

## 資料結構

1. **世界錨定**：turn-1 首幀視口＝世界原點；累積位移 O_t＝逐次
   平移的量測和；每幀以格線相位吸附（位移 mod 格距），漂移只能
   整格跳。
2. **知識圖**：`knowledge[cell] ∈ {UNKNOWN, EMPTY, UNIT(目擊),
   STALE(目擊, 前代)}`，僅界內格。EMPTY（掃過無單位）與
   UNKNOWN（沒掃）是不同事實，必須分開。
3. **邊界旗**：`boundary[D] ∈ {未發現, 已定於線}`（四方向）。
   OUT_OF_MAP 只能由撞邊事件建立（高信度 <40px 停滯），永不
   進待掃格；未發現的方向旗本身是強制待掃項。**地圖幾何不衰
   效**（邊界旗跨代保留），單位知識衰效。
4. **完成判準（建構性）**：四旗全定 ∧ 界內無 UNKNOWN/STALE
   → `board_synced`。

## 待掃格演算法（缺口暴露與補掃）

- 待掃格＝界內與已觀測格相鄰的 UNKNOWN/STALE ＋ 未定方向旗。
- 微步驟：沒有待掃格→完成；否則聚類（連通分量）→ 選目標（近者
  優先、**含 STALE 的聚類加權優先**——單位大概率在附近、威脅評
  估最需要）→ 往質心平移一步 → 重複。
- 終止保證：每步要嘛觀測新格、要嘛定一條邊，單調進展。
  平移次數上限只當防失控保險絲，不是完成判準。

## 位移量測與五層防禦

0. **單次平移距離規則**：單次平移指令 ≤ 無歧義量測範圍的一半
   （窗 1600px → 單次 ≤350px）——重複執行（2×）仍可直接量到，此
   時照量入帳、被跳過的帶留 UNKNOWN 由待掃格回補，不構成錯誤。
1. **主里程計＝相位相關**：整個地圖區域紋理（含格線——
   `grid_on` 前置保證永遠有紋理），量測窗 ≥2× 最大位移
   （7/19 繞回反號教訓條文化）；HUD 挖洞遮罩。
2. **指令合理範圍閘**：量測值必須落在 0~1.5× 指令、同軸同號，
   否則視同 unlocalisable——量測窗繞回誤判產生的「自信錯值」全
   擋。指令不寫覆蓋、只閘量測。
3. **格線相位交叉驗證**：量測窗繞回誤判的值差一個窗寬、窗寬
   mod 格距 ≠ 0，相位對不上即拒收；無特徵帶（空曠區）退化為
   「格線相位定小數＋指令先驗定整數格」，僅在執行誤差 ≥ 一整格
   時選錯桶（該情形由合理範圍閘攔）。
4. **單位排列比對＝全域重定位器**（非主里程計）：定位中斷後拿
   當前密度峰對已記目擊解偏移重錨。
5. **撞邊重錨＝絕對參考**：不依賴任何特徵；定位中斷的觀測
   進島嶼（定位中斷後位置不明的觀測暫存區，等重新定位才併
   回）側緩衝，不入權威圖，重錨成功才併，失敗丟棄（該區留
   UNKNOWN）。最壞復原＝開到最近已知邊歸零，成本有界。

安全網不變式：**無「量錯寫入」路徑**（合理範圍＋相
位雙閘）、**無「無聲丟失」路徑**（凡未觀測必為缺口、
待掃格必回補）。

## 衰效（expire，敵回合過完）

UNIT→STALE、EMPTY→UNKNOWN（敵可能移入）、generation+1
（執行器換代重置游標，防舊位移殘留——既有機制沿用）；
`zoomed` 與邊界旗不歸零。STALE 永不出沙盤當現況（動態永不
cache 不變），只作補掃優先序與 belief 層提示。

## 符號層接口

- 規劃器仍只看 `board_synced`（定義改為沒有待掃格）；
  `SurveyBoard` 的 applicable/progressed 語意不變、前置條件
  （grid_on、roster_collapsed）不變。
- `StageState.swept` 方向集淘汰或改為覆蓋率記帳——交付時提案。
- journal 逐 tick 記：覆蓋率、待掃格聚類數、unlocalised 次數、
  島嶼事件（隔離／重錨／丟棄）。

## 測試策略

- **合成世界**：已知單位擺位＋腳本化位移量測，注入吃指令、重複
  執行、unlocalisable、量測窗繞回誤判各劇本，斷言：最終覆蓋完
  整、四態逐格正確、合理範圍閘攔截繞回誤判、島嶼丟棄誠實、跳過
  帶被回補。
- ex2if map_scan fixtures 回放為半真實案例。
- 實機驗收（複驗輪）：UC HARD 1 收斂到 board_synced、cells
  非空、格座標與 2b-2 人工普查（±1 格）對照。

## 假設與擴充位

- 地圖矩形假設（現有證據全部支持：規則格網、四邊直線收在地圖外
  的星空背景）；非矩形時撞邊事件退化為逐視口帶記邊界輪廓，資料
  結構不重做。
- pinch 可用時 zoom_out 照舊執行（截圖變少），不可用時本模型
  照樣收斂——這就是 v2 的核心目的。
