# 主迴圈要支援的情境（整理清單）

> Type: working—#95 期間的情境清單；#95 結束前經使用者同意後刪除

起始日：2026-10-05。主迴圈要支援哪些情境，到目前為止沒有定義。本檔
只整理已經記錄過的情境與出處，不判斷每個情境由穩定的主迴圈處理，還是
由可抽換的 agent planner 處理；歸屬在後續討論決定。

出處中的「§」指 `docs/roadmaps/replan-main-loop.md` 的章節。

## 5. 歸屬

依已確認的規則判斷。主迴圈與 agent planner 的分工：

- 主迴圈（穩定）：讀幀、等靜止、核對前提、套用危險帶、送手勢、分類
  結果、回報證據。控制層只回報事實，不重試、不停手（§5.12.9）。
- agent planner（可抽換）：由證據修訂信念、管理意圖、選擇動作，並決定
  等待、繞開或停手（§5.12.9、§5.12.12）。

多數情境由兩邊分工：主迴圈產生證據，agent planner 決定怎麼回應。

| # | 主迴圈 | agent planner | 依據 |
|---|---|---|---|
| 1.1 | 經由 interpreter、mapparser 把幀讀成證據 | 由證據修訂信念 | §5.11、§5.12.12 |
| 1.2 | verify 判定沒有落在預期結果，回報 None | 決定重送、改走其他路徑或停手 | §5.12.9 |
