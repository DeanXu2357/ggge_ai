# 實機迴圈坑冊

> Type: how-to—must match the current workflow

十八輪實機燒出來的守則，逐條「守則＋為什麼」。**動實機迴圈的碼之前先讀
這一份**。每條都有現行程式基質（括號內），事故全文與 run 證據在本檔
git 歷史（0806 版）與 data/runs/ 流水帳。

## 判定與讀值

1. **畫面判定一律輪詢；終止類判定要連續同答案才算數**
   （`runtime/entry.py` 的導航／棄戰閘門即此制）。單發 classify 會在
   轉場動畫中途讀到底下那一層。
2. **讀值前先等讀值區自己停下來；讀不齊就重拍重讀（上限三次）。**
   半透明淡入幀「形狀在、顏色被稀釋」，字模過得了、數值全 None。
   保險是重試，不是調鬆門檻。（`stage/survey.py _settled_capture`）
3. **等待用落定判定（連續兩張幀在量測區的變化比例 < 0.06 才算落定），
   不用固定 sleep 賭。** 固定秒數拍到的是「面板剛收、鏡頭還沒跳」的
   那一瞬（sweep_scan `Camera.settled`）。
4. **「畫面對」不等於「盤面可用」**：地圖點擊前置＝classify 是
   battle_map **且**卡條收合（`runtime/screens.read_roster_strip`）；
   讀不出來就拒點。畫面名回答不了「我要用的東西還在不在」。
5. **鏡頭動過，舊視圖的格號全部作廢**——重拍重讀一次，仍讀不出才計
   lost。**沒有「沿用上一幀」這個選項**（拿 None.grid 直接 crash 的
   教訓）。

## 點擊安全

6. **危險帶不放寬；知道自己在做什麼的呼叫端帶 intent 白名單**
   （`runtime/device.py DANGER_BANDS`，如 abandon／confirm）。
7. **能不能點，權威是 `device.blocked_for_map_tap`**；照可見 UI 畫的
   排除遮罩只是第一層粗篩，追不完帶的形狀。
8. **一律不盲點固定座標——先看畫面再決定**。同一座標跨畫面是不同的
   鈕（例：(1798,971) 行動模式下是「返回」、純地圖上是「單位列表」
   開關，盲點會把卡條打開、之後每幀格網全滅）。認不出畫面就回報失敗。

## 推鏡與標記（sweep_scan／marchkit 機制）

9. **逐手勢驗收：發出去 ≠ 生效**（`runtime/marchkit.Marcher.pan`）。
    省電鎖會無聲吞掉整把手勢；判定被吃就 `ensure_unlocked(force=True)`
    後同一把原樣重發，連吃就停手。夾停（PINNED）與被吃（EATEN）分開
    處理——夾停改方向即可。**推不動永遠不等於有界線。**
10. **推鏡基準幀必須是種標記的驗收幀**（`marchkit.Seed.frame` 契約）：
    基準與驗收是同一張、中間不准有任何點擊。拿種標前的舊幀當基準，
    量到的位移會混進重種那一跳。
11. **沒驗收的點擊不算數**（`marchkit.place_marker`／`marker_gone`）：
    填色沒出現在被點的那一格就不算種上；記著的標記當下這幀看不見就
    當它沒了，不准拿「幾何上應該在窗內」當證人。
12. **種標候選格心必須落在偵測權威區內**（`board.MAP_REGION`）——
    「畫面上看得到」與「偵測器看得到」是兩個區，種在頂帶盲區＝填色
    出現了但 find_marker 永遠看不到。
13. **界判定四側都問兩個訊號**：`sweep.read_borders` 終止邊為權威、
    FrameGrid bound 只當佐證（北界有 HUD 假脊，只認終止邊）。
    推不動＋界可見＝到界；推不動＋界不可見＝連兩把就放棄該軸，
    不對著推不動的方向空轉。

## 帳本紀律

14. **不得使用盤面上的縮圖辨識身分**（0806 使用者裁決）：同型量產機
    的縮圖像素不可分，圖案內容一律不進身分判定。身分只由兩種證據
    回答：畫面讀出的數值反查名冊（數值組合唯一才算數）、或位置證據
    （已驗證世界座標的格＝身分載體）；點擊只取「這一格有東西」這個
    bit。
